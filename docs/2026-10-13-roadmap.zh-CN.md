## 1. 优先级

**Phase 3b 收口 → 固定路径上的配位 / 电子态联合跟踪 → heme 多态覆盖 → QM/MM → 核空间耦合。** XL-BOMD、更多后端、自适应 QM 区暂放后面。

最近一轮只围绕三个交付：**完整验收结果、可解释的成本报告、冻结的下一阶段实验协议。**

1. **完成 Phase 3b，建立可信的起跑线。** 收齐 DF 修复后的复跑结果，固定源码版本、参数和参考数据。覆盖与成本分别验证：
   - 覆盖：解决对称起点破缺后漏态、持续 unknown 不升级；补齐 traj2 0–59 全程。
   - 成本：两段筛选先影子验证、再实际淘汰；区分初始化、常规发现、恢复搜索，保留 scratch 兜底。
   - 分别比较"只改性能""只加强发现""两者结合"。最终门槛：原精度下覆盖通过、总成本下降。
2. **搜索做成有预算、可恢复的机制。** 通过第一段后按既定顺序做任务级并行（重点验证选中态的梯度路由与 re-seat 退路），再按实测决定 DF / 格点共享。形成稳定语义：候选已确认 / 未收敛 / 未尝试 / 因预算停止；何时加强搜索、何时报告覆盖不足。
3. **固定 QM、给定核路径上的配位事件与电子态联合跟踪**（承接 `docs/coordination-electronic-lineage-research-design.zh-CN.md`，Stateweaver）。从 Fe 六水单配体拉远 / 返回开始，再做配体交换。逐 lineage 保存距离、键级、电荷、自旋与事件历史，区分同一态上的配位变化与选态切换造成的描述符跳变。先验证观察器，再让配位信号参与调度；判据：同样预算下漏态更少，或同样覆盖下更省。调度无收益时，监测与解释能力独立保留。
4. **扩到 heme，建立多态参考集。** 从小 heme 模型开始，逐项加相邻自旋扇区、broken-symmetry 候选、稳定性检查；每种候选来源都要有参考搜索与留出路径。衡量低能态召回率、最低态遗漏率、静默换根与成本。Fe²⁺ 验收只覆盖已有自旋扇区，扩展后的覆盖要重新取证；电子结构方法的物理准确性单独核验。
5. **完整 QM/MM 与核空间算法。** 小模型 → 点电荷环境 → 蛋白 QM/MM；先验证 QM/MM 双侧力、边界处理、能量一致性，再接短程 MD、路径优化，随后 TS / NEB / MECP。接口明确区分：跟随指定态、选择最低态、返回多个态的能量和力。
