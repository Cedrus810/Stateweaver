# 近重复候选的影子跟踪（G2 失败的修法提案）

日期：2026-10-26。状态：**Claude 提案**（用户原话 2026-10-26："可以"，指同意先写这一页方案；2026-10-28："你简单冒烟之后我给你丢cpu节点"——按本文实现、冒烟，再上 PBS。"未确认"一节的参数仍未经用户确认）。依据：`state.md` §4.22、§4.24、§4.25（R2 / R2′ / E6 / E7 实测）；设计备忘 `docs/2026-10-23-phase3b-open-design-questions.zh-CN.md` §2、§7。

## 1. 要解决的问题

traj2 第 0 步，起点搜索有时同时收敛出 B（+0.6962 mHa）和一个几乎重合的 B′（+0.6929 mHa）：σ(B, B′) = 0.992、ΔE = 0.003 mHa。σ ≥ 0.9 判为同一个态，去重留下更低的 B′、丢掉 B。之后两者分开（第 2–5 步 ΔE ≈ 0.011 / 0.048 / 0.143 / 0.2 mHa），第 5 步 B 成为最低态时 beam 里没有它 → WARN（R2、R2′ 的 t2）。

事实约束：
- **出生时分不开**：σ 0.992、ΔE 0.003 mHa，σ 与能量判据都在噪声内（2b 要到 σ 0.999 才分得开，会拆开 66% 的同态对；2c 的能量条件无效）。
- **是随机的**：起点搜索不能逐位复现（E7：同一组核两次结果不同）；R2 / R2′ / E7 共 14 次搜索里约 4 次出现这类近重复候选。
- **分开后容易认出**：到第 3–4 步 ΔE 已到 0.05–0.14 mHa。

结论：不在出生时判，而是把被并掉的近重复候选**再跟几步，等它们自己分开**。

## 2. 做法

1. **登记影子**：去重 / 准入把候选 Y 判为已保留帧 X 的同一个态时，若 σ(X, Y) < σ_shadow，且 Y 在 keep_window 内，就把 Y 记为 X 的影子。每个 X 最多一个影子，取 σ 最低的那个（与 X 差得最多的）。
2. **推进影子**：每步像 pending 续算一样，从影子的上一帧 IMOM 推进一次（`cap_near`，不回退，不算梯度），任务标签 `shadow`，与其他发现任务一起走执行器（可并行）。
3. **判定**：推进后与 X 当前的帧比较：
   - σ ≥ σ_shadow → 两者确实是同一个态，丢掉影子；
   - σ < 0.9，或 |ΔE| > accept_de（0.05 mHa）→ 已分开，作为普通候选交给准入（准入、容量、替换规则不变）；
   - 都不是 → 继续跟；
   - 跟满 K 步仍未分开，或影子不收敛 → 丢掉，trace 记下。
4. **不改**：同态判据 σ ≥ 0.9、准入 / 合并 / 选态规则、验收判据（含 2d）都不变；影子不算 lineage，不出现在输出的 manifold 里。

## 3. 预期在 t2 上的效果（推演，未验证）

第 0 步 B 登记为 B′ 的影子。第 3 步 ΔE ≈ 0.048 mHa、第 4 步 ≈ 0.14 mHa > 0.05 → 第 4 步交给准入。B（+0.044）低于第三条 lineage（+0.627），满员时替换它 → 第 5 步交叉时 B 在 beam 里，选中 B（同态）。

## 4. 代价（估计）

每个搜索步后最多"窗口内的态数"个影子（traj2 第 0 步窗口内 4–6 个态），每个每步一次短 SCF。B 被连续跟踪时每步 5–25 循环（§4.13），约 5–20 s，可并行；影子最多活 K 步。按此估计，每次搜索后的 K 步里每步多约 1–2 min 工作量（4 worker 下更少）。未实测。

## 5. 验证（确定性对照）

起点搜索是随机的，直接重跑 traj2 碰不上 B′。改用 R2′ t2 存下的起点候选帧（`benchmarks/out/r2p_pbs_20261025/frames_t2/traj2_000_search.npz`，里面同时有 B 和 B′）：第 0 步把这批候选注入搜索结果，之后第 1–6 步正常跑；**关影子**应复现第 5 步 WARN，**开影子**应在第 5 步判同态。只跑 7 步，在 183 上约 20–30 min。通过后再在 PBS 上跑 traj2 × 4（R2″）判 G2，对称起点 × 4 复核 G1 不受影响。

## 未确认（Claude 推断）

- **σ_shadow = 0.999**：§4.24 中 σ ≥ 0.999 的 438 对 |ΔE| ≤ 0.015 mHa，与同态收敛噪声（≤ 0.016 mHa，§4.8）一致；σ < 0.999 的对里才出现明显能量差。只在 Fe²⁺(H₂O)₆ / B3LYP 上测过。
- **分开的判据用 accept_de = 0.05 mHa**（约 3 倍收敛噪声，现有容差，不新增）。
- **K = 5**：t2 的 B / B′ 在第 3–4 步 ΔE 越过 0.05 mHa，K = 5 留一步余量。只有这一个例子。
- **每个 X 只留一个影子**：为了控制代价；若同一个 X 有两个以上真正不同的近重复候选，会漏掉其余的。
- 第 3 节的推演与第 4 节的代价都没有跑过。
